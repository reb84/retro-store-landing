# STATIC ATTIC - Vintage Tech & Retro Collectibles

![Screenshot](assets/screenshot.png)

✨ [LIVE DEMO](https://reb84.github.io/retro-store-landing/)

STATIC ATTIC is a single-page landing site for a fictional shop selling vintage game hardware, Y2K oddities, and forgotten tech. All the chaos of the early internet, but with modern accessibility and SEO underneath.

---

## Features

- Late 90s / early 2000s web aesthetic
- Pixel fonts, marquee banners and Windows 95-style title bars
- Scanline overlays and visitor counter
- Semantic, accessible HTML underneath all the chaos
- No JavaScript - CSS only
